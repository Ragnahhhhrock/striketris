Rules

  • Use a token, never a raw hex, in CSS. JavaScript block colours come from SHAPE_TINT.
  • One bomb red element per view.
  • HUD text sits on a panel, never directly on the 3D view.
  • Every control has a visible focus ring.
  • Motion answers game state only.
